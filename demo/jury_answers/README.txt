The actual Darija response is:
الجواب المبني على المصادر ما متوفرش دابا.

Darija is DEGRADED. Logs show a RateLimitError during grounded generation,
an 8-second internal retry, then generation_provider_error. Retrieval returned
five chunks, but the generation step failed. This is not a language detection
failure: the response remains Moroccan Darija in Arabic script.
Azure final composition accepted the controlled error response.
The failed response was not replaced by a hand-written or retried successful answer.

The French answer explicitly states that the retrieved excerpts do not detail
the return and risks of equities; this limitation remains in the saved answer.
The Arabic answer is in Arabic and retains some French technical labels in
parentheses, exactly as the backend returned them. There was no French fallback.

The final composer is azure_openai with composer_status=accepted for all four
requests. Composer acceptance does not mean grounded generation succeeded.

PIPELINE AND PERSISTENCE

Traces confirm security, memory context, Supervisor, routing, RAG, the selected
agent, graph completion and Azure final composition on each request.
The normal graph/output guard is unchanged; no node or dependency was replaced.
French, English and Arabic each produced two persisted history messages
(user and assistant), matching the captured text exactly. The Darija error
produced zero history messages, following the backend's existing error policy.

Latency measures the full HTTP round trip. French includes cold initialization;
later requests used the same warmed backend. These are one-run observations,
not guaranteed timings or deterministic promises for a future live demo.

AUDIO

See ../jury_answers_audio/README.txt and audio_manifest.json.
Available full WAVs speak the exact saved answers.
Long answers are sent to the same configured Gemini TTS model/voice as ordered
text segments; concatenating the segments reproduces the full answer exactly.
When the full recording exceeds 45 seconds, a separate *_response_demo.wav is
marked as a SHORTENED PLAYBACK VERSION using the first three complete sentences.
The full TXT/JSON remain available for all four languages.
